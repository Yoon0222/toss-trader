# 작업 기록

피넛의 worklog에서 이식했다. docs/WORKLOG.md의 열린 항목과 최신 날짜 절을 먼저 읽는다.
Asia/Seoul 기준 YYYY-MM-DD 날짜 절을 하루에 하나만 두고, 새 작업을 해당 절 맨 위에 추가한다.
무엇을 바꿨는지, 이유, 파일, 실제 검증 결과와 남은 일을 짧게 기록한다. 완료 항목은 삭제하지 않고 체크한다.
테스트 통과·서비스 연결·실전 검증을 구분한다. 키·토큰·계좌번호는 기록하지 않는다.
외부 문서나 피넛 Notion 페이지에는 기록하지 않는다. 외부 동기화 요청은 지정된 목적지와 권한을 확인한다.
