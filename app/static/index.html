실제 데이터 연결

토스증권 WTS → 설정 → Open API에서 키를 발급하고 이 서버의 공인 IP를 허용 목록에 등록해 주세요.

프로젝트 .env 설정
TOSS_CLIENT_ID=발급받은 값
TOSS_CLIENT_SECRET=발급받은 값
TOSS_ACCOUNT_SEQ=계좌 식별값

설정 위치: PythonProject / toss-trader / .env
계좌 식별값은 토스 계좌 목록 API의 accountSeq이며 계좌번호가 아니에요. 계좌 조회가 필요할 때만 설정하세요.

키와 토큰은 채팅이나 브라우저에 입력하지 마세요. 설정한 뒤 서버를 재시작하면 조회가 시작돼요.
